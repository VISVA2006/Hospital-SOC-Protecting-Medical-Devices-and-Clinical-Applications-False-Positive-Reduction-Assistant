## 1. Project Overview

In a hospital Security Operations Center (SOC), analysts face overwhelming volumes of security alerts generated by connected medical devices (e.g., infusion pumps, ventilators, patient monitors, MRI/CT scanners) and healthcare workstations. Over 70% of these alerts are repetitive false positives (routine vulnerability scans, HL7 burst messages, maintenance windows). This leads to **severe analyst alert fatigue**, creating acute risk of missing critical threats.

The **Hospital SOC False-Positive Reduction Assistant** is an end-to-end, defensive cybersecurity prototype designed to safely filter repetitive false positives while strictly **preserving novel and dangerous attacks** targeting life-critical clinical assets.

> [!IMPORTANT]
> **Defensive Cybersecurity Prototype Notice:** This project uses 100% synthetic, clinically modeled telemetry. It does NOT connect to real hospital networks, live patient databases, or physical medical equipment.

## 2. Key Architecture & Features

1. **Event Stream Integrity Engine (`src/event_processor.py`)**:
   Reconciles duplicate event storms, records network latency on delayed events, and re-sequences out-of-order streams into strict chronological order.
2. **Supervised Threat Classifier (`src/train_model.py`)**:
   Class-balanced Logistic Regression with Scikit-learn Pipeline encapsulation, prioritizing **Recall and minimum False Negative Rate** over raw accuracy.
3. **Novel Threat & Anomaly Detection (`src/anomaly_detection.py`)**:
   An **Isolation Forest** anomaly detector flags novel attack vectors, ensuring unseen telemetry patterns are never automatically suppressed.
4. **Temporal Sequence Risk Tracking (`src/sequence_detection.py`)**:
   A rolling 60-minute time window tracks event velocity, unique destinations, and failed authentications to intercept low-and-slow reconnaissance.
5. **Deterministic Clinical Safety Guardrails (`src/safety_guardrail.py`)**:
   Deterministic healthcare policies mandate that critical medical devices (Ventilators, Infusion Pumps, ICU Monitors) exhibiting abnormal telemetry can **never be auto-suppressed**. Fail-safe fallback guarantees the system fails open to human review on any telemetry parsing exception.
6. **Continuous Learning & Anti-Catastrophic Forgetting (`src/retraining_pipeline.py`)**:
   Experience Replay Buffer (80% historical baseline, 20% validated analyst feedback) with strict promotion gates (threat recall $\ge 98\%$, critical device recall $= 100\%$).
7. **Model Registry & Governance (`src/model_registry.py`)**:
   Centralized metadata tracking (`models/model_registry.json`) for active champions, isolated candidates, audit history, and deterministic one-click rollback.
8. **Enterprise FastAPI Microservice (`app/api.py`, `app/services.py`)**:
   Production-ready REST API with Pydantic schemas, supporting single-alert triage, batch stream processing, feedback capture, and health probes.
9. **Interactive Streamlit Workspace (`app.py`)**:
   Full 11-page analyst workspace covering Executive Dashboard, Investigation, Event Integrity, Evaluation, Feedback, Error Analysis, Drift Monitoring, Retraining, Model Registry, Adversarial Suite, and Threshold Calibration.
10. **Adversarial Evasion Suite (`experiments/adversarial_tests.py`)**:
    12 specialized healthcare adversarial attack scenarios (ADV-01 through ADV-12) demonstrating 100% defense immunity.

## 5. Quick Start & Execution Guide

### 5.1 Environment Setup
```bash
# Clone the repository and navigate to directory
cd hospital_soc_fp_assistant

# Create virtual environment (Python 3.10 recommended)
python -m venv venv
venv\Scripts\activate  # On Linux/macOS: source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 5.2 Run All Automated Tests (23 Tests)
```bash
pytest -v
```
*Expected: 23 passed in ~10 seconds.*

### 5.3 Run Master Experiment Orchestration Pipeline
```bash
python run_all_experiments.py
```
*Executes data leakage audit, deep error analysis, noise robustness sweep, drift detection, 12 adversarial attacks, 63-point threshold calibration, and operating points in ~98 seconds.*

### 5.4 Launch Interactive Streamlit Analyst Workspace
```bash
streamlit run app.py
```
*Opens interactive 11-page dashboard in your browser (`http://localhost:8501`).*

### 5.5 Start FastAPI REST Microservice
```bash
uvicorn app.api:app --host 0.0.0.0 --port 8000 --reload
```
*Explore interactive Swagger API documentation at `http://localhost:8000/docs`.*
